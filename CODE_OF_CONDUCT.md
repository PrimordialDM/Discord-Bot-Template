# Code of Conduct

## Our Standard

This project is intended to be useful, practical, and welcoming to developers building Discord bots.

Examples of behavior that contributes to a positive environment include:

- being respectful and constructive
- focusing feedback on code, documentation, and design decisions
- helping other contributors understand tradeoffs clearly
- keeping discussions practical and on-topic

Examples of unacceptable behavior include:

- harassment or personal attacks
- discriminatory or abusive language
- deliberately disruptive behavior
- sharing secrets, tokens, or sensitive configuration from others

## Enforcement

Project maintainers may remove, edit, or reject contributions, comments, or issues that violate this code of conduct.

## Scope

This code of conduct applies in repository discussions, issues, pull requests, and other project spaces.

## Reporting

If someone is violating this code of conduct, report it privately to the repository maintainer.
